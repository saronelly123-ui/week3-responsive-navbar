# Week 3 Workshop 1 — Responsive Navbar

A responsive navigation bar built with Tailwind CSS utility classes.

## Features
- Brand name on the left
- Four navigation links and a Get Started link
- Mobile hamburger menu that opens and closes
- Desktop navigation from the `md` breakpoint upward
- Hover and keyboard focus styles on links and buttons
- No custom CSS; Tailwind is loaded using its CDN for easy workshop testing

## Run locally
Open `index.html` in your browser. An internet connection is needed for Tailwind CDN.
